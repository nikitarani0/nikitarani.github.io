Built for the CDAC Hackathon 2026. A Linux observability platform that layers
security intelligence on top of standard system monitoring — surfacing anomalies
an ops-only dashboard would miss.

**Stack:** Python, FastAPI, Prometheus, Ollama, React, Docker

**Key capabilities:**
- Real-time system metrics via Prometheus, visualized in a React dashboard
- Local LLM-driven anomaly detection and plain-language security summaries
- Fully containerized deployment via Docker
