Built for the **Google Cloud AI Builder Cup 2026** (Team VISN, Future of Work theme).

A security control plane that mediates, monitors, and constrains autonomous AI
agent actions in enterprise environments — addressing a gap most AI tooling
ignores: agents acting with real permissions need the same policy enforcement,
audit trails, and DLP controls as human operators.

**Stack:** Gemini, Cloud Run, Firestore, Vertex AI, Model Armor, DLP, Pub/Sub, React

**Key capabilities:**
- Real-time policy enforcement on agent tool calls
- DLP-integrated output filtering to prevent sensitive data leakage
- Full audit trail via Firestore + Pub/Sub event streaming
