I'm a Cloud Security Engineer at [Qualys Security TechServices](https://www.qualys.com/), working
across six cloud platforms — AWS, Azure, GCP, OCI, IBM Cloud, and Alibaba Cloud — specializing in
vulnerability management, cloud security posture management, access provisioning, and network
security operations. I deploy and operate Qualys's own enterprise security products, VMDR and
CSPM, across production environments.

I'm proficient in Python scripting and REST API automation for cloud infrastructure tasks,
collaborate cross-functionally with DevOps and Platform teams, and focus on translating complex
security findings into clear documentation for both technical and non-technical stakeholders.

Over four years of continuous cybersecurity skill development, I've built hands-on experience in
network security, Linux administration, DevSecOps pipelines, SIEM implementation, and offensive
security fundamentals — through tool building, independent security research, and academic
training. I write about this work at [medium.com/@nikitarani0110](https://medium.com/@nikitarani0110).

**Certifications:** CEH · CompTIA Security+ · ISC2 CC · Qualys VMDR

**In progress:** OSCP
